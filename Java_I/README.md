# Java I — Pasaporta digjitale

## Çka kom realizu

Kom kriju nje pasaporte digjitale per nje personazh te sajum, i cili kandidon si udherrefyes i kampusit.

Projekti permban:
- index.html
- rreth.html
- lidhje relative mes faqeve
- liste me tri aftesi

## Qysh hapet projekti

Prej folderit JavaI startohet serveri lokal me:

python3 -m http.server 8000

Pastaj ne browser hapet:

http://localhost:8000/

## Testet

Hyrja:
http://localhost:8000/

Rezultati qe pritet:
Faqja index.html me u hap normalisht dhe lidhja per te rreth.html me funksionu pa gabim 404.

Rezultati qe kom marr:
Faqja u hap me sukses dhe lidhjet vajtje/kthim funksionuan pa problem.

DevTools Network:
- URL: http://localhost:8000/
- Method: GET
- Status: 200 OK
